Cara kerja

Proses yang jelas dari awal sampai akhir, dengan ritme Scrum yang sudah saya jalankan lebih dari 3 tahun sebagai Scrum Master.

  1. Diskusi dan estimasi

    Kita bahas tujuan dan batasan proyek. Sebelum mulai, Anda sudah tahu estimasi waktu dan biayanya.

  2. Sprint pendek

    Pekerjaan dibagi per sprint dua mingguan dengan target yang jelas, jadi Anda selalu tahu apa yang akan selesai berikutnya.

  3. Laporan dan demo rutin

    Anda melihat kemajuan nyata lewat demo berkala dan laporan singkat di Slack atau WhatsApp. Tugas dilacak di Jira, tanpa kejutan di akhir.

  4. Serah terima

    Anda menerima kode teruji, dokumentasi, dan panduan penggunaan, sehingga tim Anda bisa meneruskannya tanpa bergantung pada saya.

Sistem manajemen kuota impor baja

Aplikasi web dan layanan backend untuk perusahaan trading baja di Indonesia

Sistem ini membantu tim EXIM mengelola kuota impor dengan lebih terkontrol: mengunggah dokumen izin kuota, memeriksa perbedaan data sebelum diterbitkan, lalu memantau pemakaian kuota di setiap pembelian.

  • Dokumen kuota PDF (SPI dan USDFS) dibaca otomatis oleh parser buatan sendiri, lalu perbedaannya dicek sebelum dipublikasikan, sehingga risiko salah input berkurang.
  • Dashboard realisasi menampilkan kuota terpakai, tertahan (on hold), dan tersisa, plus estimasi per bulan.
  • Purchase order dapat diimpor dari Excel dan menahan kuota secara otomatis.
  • Riwayat perubahan kuota per kode HS dan pelabuhan tujuan, sehingga setiap perubahan bisa ditelusuri.
  • Arsitektur microservice: ASP.NET Core 9, JWT, HMAC, RabbitMQ, Docker.
  • ASP.NET Core 9
  • C#
  • RabbitMQ
  • Docker
  • PDF parsing
  • JWT / HMAC

Nama klien, nomor dokumen izin, data pemasok, dan identitas pengguna pada tangkapan layar telah disamarkan demi kerahasiaan.

Generator CV dengan MCP

Alat otomasi pribadi dengan C# dan Claude Desktop

Cukup minta lewat percakapan dengan Claude: server MCP buatan sendiri ini membuat CV dalam bentuk PDF dan langsung mengunggahnya ke Google Drive.

  • Satu perintah, generate_resume, membuat ulang PDF dari template HTML (PuppeteerSharp) beserta metadata PDF-nya.
  • Dapat mengganti berkas lama di Google Drive tanpa mengubah tautan berbagi, sekaligus menandainya sebagai favorit.
  • Autentikasi OAuth ke Google Drive dengan token tersimpan, sehingga tidak perlu login ulang setiap kali dijalankan.
  • Berjalan sebagai server MCP (stdio) yang terdaftar di Claude Desktop.
