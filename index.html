Cara kerja

Ritme Scrum yang sudah saya jalankan lebih dari 3 tahun sebagai Scrum Master.

  1. Diskusi dan estimasi

    Kita membahas tujuan dan batasan proyek. Anda menerima estimasi waktu dan biaya sebelum pekerjaan dimulai.

  2. Sprint pendek

    Pekerjaan dibagi per sprint dua mingguan dengan target yang jelas dan terukur.

  3. Laporan dan demo rutin

    Anda memantau kemajuan lewat demo berkala dan laporan singkat di Slack atau WhatsApp, dengan tugas dilacak di Jira.

  4. Serah terima

    Kode teruji, dokumentasi, dan panduan penggunaan diserahkan agar tim Anda bisa meneruskannya.

Sistem manajemen kuota impor baja

Aplikasi web dan layanan backend untuk perusahaan trading baja di Indonesia

Sistem ini menggantikan pencatatan kuota impor secara manual. Tim EXIM dapat mengunggah dokumen izin kuota, memeriksa perbedaan data sebelum diterbitkan, lalu memantau pemakaian kuota setiap pembelian.

  • Impor dokumen kuota PDF (SPI dan USDFS), dibaca otomatis dengan parser buatan sendiri, lalu dicek perbedaannya sebelum dipublikasikan.
  • Dashboard realisasi: kuota terpakai, tertahan (on hold), dan tersisa, serta estimasi per bulan.
  • Purchase order dengan impor Excel, yang menahan kuota secara otomatis.
  • Riwayat perubahan kuota per kode HS dan pelabuhan tujuan.
  • Arsitektur microservice: ASP.NET Core 9, JWT, HMAC, RabbitMQ, Docker.
  • ASP.NET Core 9
  • C#
  • RabbitMQ
  • Docker
  • PDF parsing
  • JWT / HMAC

Nama klien, nomor dokumen izin, data pemasok, dan identitas pengguna pada tangkapan layar telah disamarkan demi kerahasiaan.

Generator CV dengan MCP

Alat otomasi pribadi dengan C# dan Claude Desktop

Server MCP buatan sendiri yang membuat CV dalam bentuk PDF lewat percakapan dengan Claude, lalu mengunggahnya ke Google Drive.

  • Satu perintah, generate_resume, membuat ulang PDF dari template HTML (PuppeteerSharp) beserta metadata PDF-nya.
  • Dapat mengganti berkas lama di Google Drive tanpa mengubah tautan berbagi, sekaligus menandainya sebagai favorit.
  • Autentikasi OAuth ke Google Drive dengan token tersimpan, sehingga tidak perlu login ulang setiap kali dijalankan.
  • Berjalan sebagai server MCP (stdio) yang terdaftar di Claude Desktop.
  • C#
  • .NET
  • MCP
  • PuppeteerSharp
  • Google Drive API
  • OAuth2
